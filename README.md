
# Новостной сайт: реализация разделов (тегов) для статей

## Описание задачи

Было решено добавить тематические разделы (теги) к статьям на новостном сайте. Каждая статья может относиться к нескольким разделам, но **один из них должен быть основным**. Основной раздел отображается первым, остальные — в алфавитном порядке.

Требования:
- Реализовать модели `Tag`, `Article`, `Scope`.
- В админке можно указывать разделы для статьи.
- Обязательно наличие **ровно одного** основного раздела.
- Отображение тегов в шаблоне: основной — синий (`badge-primary`), остальные — серые (`badge-secondary`).

---

## Внесённые изменения

### 1. Модели (`models.py`)

#### `Tag`
- Простой тег с уникальным названием.
- Сортировка по алфавиту.

#### `Article`
- Содержит заголовок, текст, дату публикации, изображение.
